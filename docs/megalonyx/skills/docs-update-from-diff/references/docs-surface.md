# Docs Surface Map Documentation

## Purpose
This file acts as a routing guide for documentation contributors, mapping specific types of content to their correct destination pages within the `docs/` directory.

## Logic & Structure
The map is divided into:
- **Primary Sections**: A directory of the main documentation hubs (e.g., `docs/users/overview.md` for entry points, `docs/developers/tools/*.md` for implementation details).
- **Navigation Rules**: Instructions on how to update `_meta.ts` files to ensure new pages are discoverable in the generated documentation site.
- **Placement Heuristics**: Best practices for deciding where to put a change (e.g., "put it where a reader would naturally look first", "avoid duplicating long explanations").

## Usage
- **Contributors**: Use this map to determine where to add new documentation or where to update existing pages when a feature changes.
- **AI Agents**: Use this as a "routing table" when tasked with updating documentation based on a code diff.
