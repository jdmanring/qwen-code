# .env.example

`config/megalonyx/.env.example` is the template for the Megalonyx runtime environment file.
Copy it to `~/.local/share/megalonyx/.env` and fill in your credentials before starting any
Megalonyx service.

## Setup

```bash
cp config/megalonyx/.env.example ~/.local/share/megalonyx/.env
# Edit ~/.local/share/megalonyx/.env and fill in your real values.
```

The services (`bin/mega-memory`, `bin/mega-tasks`, `bin/mega-status`) source this file
automatically at startup if it exists at the above path.

## Variables

### Vector database

| Variable | Default | Purpose |
|---|---|---|
| `QDRANT_LOCAL_URL` | `http://localhost:6333` | URL of the local Qdrant instance. Must be running before starting `agent-memory`. |
| `QDRANT_CLOUD_URL` | (empty) | URL of a Qdrant Cloud instance. Leave empty if using local only. |
| `QDRANT_API_KEY` | (empty) | Authentication key for Qdrant Cloud. Not needed for local. |

### Model providers

| Variable | Purpose |
|---|---|
| `GEMINI_API_KEY` | Used by `agent-memory` for embedding generation via Google Gemini. |
| `OPENAI_API_KEY` | Used by OpenAI-compatible providers in the control plane. |
| `GITHUB_TOKEN` | Used by the GitHub MCP server for repository access. |

### System

| Variable | Default | Purpose |
|---|---|---|
| `MCP_TRANSPORT` | `socket` | How the memory MCP server communicates. `socket` for local IPC, `stdio` for subprocess piping. |
| `STACK_SETTINGS_PATH` | `~/.qwen/settings.json` | Path to the Qwen Code runtime settings file. |
| `QDRANT_MCP_PYTHON` | `~/.local/share/megalonyx/venvs/mcp-server-qdrant/bin/python` | Python interpreter for the Qdrant MCP server. Only needed if running Qdrant MCP in its own venv. |

## What not to commit

The live `.env` file at `~/.local/share/megalonyx/.env` is outside the repo and is never
committed. Only `config/megalonyx/.env.example` (with no real credentials) is tracked.
