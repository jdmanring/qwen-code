# 🗣️ Simple Language Guide

This guide is a "translation cheat sheet" to help agents move from technical "AI-speak" to grounded, human language. The goal is to be relatable and clear, not impressive.

---

## 🛠️ The Translation Table

When writing for humans (READMEs, guides, status reports), use the **Human-Speak** column.

| AI-Speak (Avoid) | Human-Speak (Use) | Why? |
| :--- | :--- | :--- |
| "Project Standard Alignment" | "Following the project rules" | Technical terms can be opaque; "Rules" is clear. |
| "Cognitive Friction" | "Confusing names" or "Hard to find" | "Friction" is abstract; "Confusing" is a feeling. |
| "Materialize the Blueprint" | "Install the code" or "Deploy" | "Materialize" is poetic; "Install" is an action. |
| "Semantic Entropy" | "Loss of focus" or "Forgetfulness" | "Entropy" is physics; "Forgetfulness" is human. |
| "Cognitive Synthesis" | "Planning" or "Thinking it through" | "Synthesis" sounds like a lab; "Planning" is a task. |
| "Surgical Execution" | "Precise changes" or "Targeted edits" | "Surgical" is a metaphor; "Precise" is a quality. |
| "Deterministic Process" | "Consistent result" or "Reliable" | "Deterministic" is math; "Reliable" is a benefit. |
| "Ephemeral State" | "Temporary" or "In-memory only" | "Ephemeral" is fancy; "Temporary" is plain. |
| "Cognitive-Symmetry" | "Matching docs and code" | "Symmetry" is a concept; "Matching" is a state. |

---

## 📏 Three Simple Rules for Writing

1. **The "Grandparent" Test**: If you wouldn't say it to a non-technical person to explain what the project does, don't write it in the README.
2. **Verbs over Nouns**: Instead of "The implementation of the memory system," use "We built a way for the AI to remember things."
3. **Truth over Polish**: It is better to be "boringly honest" than "impressively vague." If a feature is a prototype, call it a prototype.

---

## ❌ Common "Posturing" Traps
- **Avoid**: "Leveraging state-of-the-art paradigms to optimize..."
- **Use**: "Using a new method to make the system faster..."
- **Avoid**: "Orchestrating a symphony of specialized agents..."
- **Use**: "Using a few different agents to handle different tasks..."
