FREE ACCESS
-----------
LIMITED FREE TIER

AUTHENTICATION
--------------
- API key only

OPENAI COMPATIBLE
-----------------
NO

BEST USE CASES
--------------
- AI search
- RAG pipelines
- agent web search
- contextual retrieval

STRENGTHS
---------
- Designed specifically for AI agents
- Clean JSON outputs
- Good retrieval quality
- **Agent Skills**: Supports specialized search modes (e.g., `research`, `fact_check`) for deeper synthesis.

WEAKNESSES
----------
- Not an LLM provider
- Limited free usage

EXAMPLE ENDPOINT
----------------
POST https://api.tavily.com/search

QWEN CODE NOTES
---------------
Recommended as:
- retrieval subsystem
- web augmentation layer
- memory/context fetcher
- **Integration**: Use via MCP server for standardized tool access.
- **Strategy**: Pair with the `researcher` skill for deep-dive synthesis.
