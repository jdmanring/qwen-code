 
# System Settings Configuration

This document mirrors `config/meta/system_settings.json`.

## Parameters
- `system_name`: The official name of the project.
- `version`: The current semantic version of the stack.
- `stability_level`: The current phase of the project (e.g., alpha, beta, hardening, production).
- `default_transport`: The primary communication method for MCP servers.
- `max_retries`: Global limit for tool execution retries before failure.
